## 📚 What I'm Learning

These are learning priorities, not claims that I've mastered every topic.

### 🐧 Linux & System Administration
I am interested in Linux as a practical platform for hosting services and learning how computers operate. My experiments have involved Ubuntu Server, Raspberry Pi OS, command-line administration, Docker, and self-hosted services.

My next steps are to improve my understanding of users and permissions, processes, services, logs, storage, updates, SSH, backups, and basic server hardening.

### 🌐 Networking
I'm building my networking fundamentals, including IP addressing, subnetting, TCP/IP, DNS, DHCP, ports, routing, and how devices communicate across a local network.

I want to get more comfortable troubleshooting connectivity systematically and understanding what network tools report, rather than simply running commands without understanding the results.

### 🔐 Cybersecurity
My long-term goal is to work in ethical hacking and/or a Security Operations Center (SOC). I'm approaching cybersecurity through foundations first: Linux, networking, system security, logs, and basic scripting.

Topics I want to develop include:
- Security fundamentals, authentication, access control, and least privilege.
- Network reconnaissance and service discovery in systems I own or have permission to test.
- Log analysis, alert investigation, and incident-response fundamentals.
- Vulnerability management, secure configuration, and defensive monitoring.
- Python scripting to automate small, repeatable tasks.

I aim to learn and practise in legal labs and on systems where I have explicit permission.

### 🐍 Programming & Web Development
I have experience with HTML and CSS and have completed web-design training. I'm working toward stronger programming skills, especially Python, JavaScript, debugging, Git, and writing code that is easier to maintain.

I want to move beyond making a page look right and become better at understanding program flow, data, APIs, error handling, and how applications fit together.

### 🔌 IoT, Embedded Systems & Automation
I enjoy experimenting with microcontrollers and connecting physical devices to software. My project interests include ESP8266/ESP32, Arduino, sensors, relays, MQTT, and Home Assistant.

I want to keep improving at reading sensor data, designing dependable automations, separating hardware faults from software bugs, and making systems easier to monitor and troubleshoot.

**Repository:** [neoxey/neox-compact-40m](https://github.com/neoxey/neox-compact-40m)

The interesting engineering challenge is reliability: keeping the software state aligned with the real hardware, avoiding false triggers, and troubleshooting how devices communicate.

## 💡 How I Like to Build

- **Start with a real problem.** Decide what the project should do before choosing tools.
- **Understand the fundamentals.** Learn the relevant hardware, operating system, protocol, or programming concepts.
- **Test in small steps.** Isolate one fault at a time instead of changing everything at once.
- **Document the result.** Keep setup steps, known limitations, measurements, and lessons learned with the project.
- **Improve iteratively.** Treat mistakes as information and make the next version more reliable.
